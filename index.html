Engineering Case Studies

16-Bit Pipelined RISC CPU Processor
Digital Logic & Architecture
Designed and synthesized a functional 16-bit RISC-like pipelined processor core utilizing VHDL. Implemented a classical 5-stage computer architecture comprising Instruction Fetch, Decode, Execute, Memory Access, and Write-Back blocks. To maintain optimal hazard bounds, integrated dedicated hardware-level pipeline stall logic to seamlessly safeguard structural execution paths across variable mathematical, logic, and branching instruction sets. Verified signal configurations across unified register files using ModelSim simulations before successfully porting the compiled RTL code down to physical Xilinx Basys 3 FPGA silicon complete with functional bootloaders.
